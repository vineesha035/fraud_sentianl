This folder holds images and generated figures for the project.

| File | Source |
|------|--------|
| `hero_fraud_detection.png` | AI-generated hero/banner for README and portfolio |

| `precision_recall_by_threshold.png` | Generated by `scripts/generate_assets.py` |

To generate the chart assets (requires `numpy`, `matplotlib`, `seaborn`):

```bash
python scripts/generate_assets.py
```

Hero and pipeline images can be re-created with an image generator or replaced with your own visuals.
